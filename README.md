# CountryPeek

A React app to explore countries using the RestCountries API.

## Live Demo
https://YOUR-USERNAME.github.io/country-peek

## Features
- Search countries
- Filter by region
- Sort countries
- Country detail page
- Dark/light mode
- Favourites (saved in localStorage)

## Tech Stack
React, Vite, React Router, CSS, REST API

## Run Locally
npm install
npm run dev
